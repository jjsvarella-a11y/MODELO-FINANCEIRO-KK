# R5 — referência técnica do fecho funcional

Checkpoint intermédio preservado para reprodução da extensão bancária R6. **A entrega atual está em [Fecho_R6_Banco](../Fecho_R6_Banco/README.md).**

Esta pasta conserva o workbook R5 e as provas de 62 verificações funcionais, antes da extensão bancária. A base R4 reconciliou 1.738.800 valores mensais, sem diferenças. As verificações utilizaram LibreOffice; Excel 365 nativo não foi testado. Os PDFs de entrega atual são os da R6, onde foi corrigida a largura da coluna do anexo de orçamento.

O Excel R5 serve como fonte reprodutível de `src/bank_r6.py`; não deve ser confundido com a versão bancária mais recente.
