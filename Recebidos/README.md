# Ficheiros recebidos

Pasta para colocar cópias do Excel alteradas no Microsoft Excel, preservando a entrega publicada.

Para ficheiros superiores a 25 MB, utilize o GitHub Desktop: copie o Excel para esta pasta, faça Commit e Push. O carregamento pelo site está limitado a 25 MB.

Não substitua o workbook em `entregas/EFCC_Final/Entrega_Consolidada` ao enviar uma nova fonte para análise.

O ficheiro vazio anteriormente chamado `Recebidos` foi convertido nesta pasta; não continha um Excel.
